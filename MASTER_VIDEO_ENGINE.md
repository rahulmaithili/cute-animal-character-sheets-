# MASTER VIDEO ENGINE — Cute Animal Social Universe

## Purpose
Generate consistent, original vertical short-form videos for the 10 established social pages in this repository.

## Source of Truth
1. Page identity and approved characters
2. Character reference sheets in `facebook_images/`
3. Page-specific rules
4. This engine
5. Individual episode brief

Never invent a new permanent character design when an approved character exists.

## GLOBAL STORY-VIDEO STYLE — REQUIRED
Every generated video should feel like a **mini cinematic story**, not a slideshow, random animation clip, or character showcase.

### Reference-Video Direction
- Strong visual hook in the first 0–2 seconds.
- One simple, instantly understandable premise.
- Clear beginning → discovery/problem → escalation → emotional or funny payoff.
- Prefer 5–8 purposeful visual beats inside the short.
- Use cinematic close-ups for eyes and expressions, medium shots for actions, and wider environmental shots for context.
- Use motivated camera movement: slow push-in, tracking, orbit, low-angle reveal, over-the-shoulder, macro insert, or gentle pull-back.
- Let actions cause the next action; avoid unrelated scene changes.
- Characters must physically interact with believable props and environments.
- Use expressive micro-acting: eye movement, blinking, breathing, head turns, tiny paw/hand gestures, hesitation, surprise and relief.
- Build emotion through visual acting rather than excessive dialogue.
- Use beautiful cinematic depth of field, natural motion blur, volumetric light, realistic shadows, detailed materials and polished 3D rendering.
- Include environmental storytelling: footprints, moving leaves, water ripples, floating dust, fireflies, fabric movement, tiny object reactions, etc., when appropriate.
- Use sound as part of the story: footsteps, cloth movement, object impacts, environmental ambience, tiny creature sounds, reaction sounds and restrained music.
- Finish with a memorable payoff, emotional beat, funny reversal, reveal or loop.
- The final shot should hold long enough to read the emotion and should never end abruptly.

### Character Performance
The character is the **actor**, not a static model. Give the character a clear intention, reaction and physical action in every beat.

### Visual Quality
Aim for premium cinematic 3D animation with believable lighting, tactile materials, expressive faces, clean anatomy and film-like composition. Do not imitate a specific studio or living artist.

## Global Output
- Format: 9:16 vertical
- Default duration: 20–35 seconds
- Hook: visual action or curiosity in first 0–2 seconds
- Story: one clear premise, escalation, payoff
- Style: premium original cinematic stylized 3D animation
- Preserve exact character identity from the reference sheet.

## Episode Pipeline
1. Read PAGE DNA.
2. Read CHARACTER LOCK.
3. Select approved character(s).
4. Pick a content pillar.
5. Create an original visual hook.
6. Define the character's goal/intention.
7. Build beginning → escalation → payoff.
8. Break into 5–8 purposeful visual beats.
9. Add camera, lighting, environment, motion and sound.
10. Run continuity checks.
11. Output one production-ready single-line prompt plus metadata.

## Continuity Rules
- No unexplained character redesign.
- No changing eye/fur/skin color.
- No clothing or accessory changes unless explicitly introduced.
- Keep age/proportions stable.
- Keep geography, weather and time of day coherent.
- Props remain consistent between shots.
- Animal anatomy remains plausible within the stylized universe.
- Do not place a character in an incompatible habitat without a story reason.
- Do not change character identity to fit the scene.

## Hook Library
Immediate problem, visual surprise, mystery object, funny mistake, chase, impossible-but-cute event, emotional reunion, transformation, countdown, direct camera interaction, unexpected discovery.

Do not repeat the same hook structure in consecutive episodes.

## Ending Library
Visual punchline, reveal, heartwarming payoff, callback, tiny twist, satisfying completion, emotional reaction, loop-friendly ending.

## Final Prompt Template
[Cinematic vertical 9:16 mini-story] + [exact approved character identity] + [0–2 sec hook] + [character intention] + [logical environment] + [5–8 connected story beats] + [specific physical actions/interactions] + [camera choreography] + [lens/depth of field] + [lighting/atmosphere] + [facial acting/body language] + [sound/SFX/music] + [payoff/final frame] + [continuity constraints] + [quality/render constraints].

## Negative Prompt
static posing, slideshow feeling, disconnected scenes, random scene changes, weak opening, character redesign, inconsistent face, changing eye color, changing fur pattern, wrong anatomy, extra limbs, duplicate character, floating objects, broken paws, warped face, inconsistent scale, random wardrobe, random accessories, unreadable text, watermark, logo, low-detail render, jittery motion, robotic movement, excessive motion blur, flicker, texture crawling, abrupt camera cuts, habitat mismatch, continuity break.
