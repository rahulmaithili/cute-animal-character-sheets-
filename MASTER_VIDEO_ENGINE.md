# MASTER VIDEO ENGINE — Cute Animal Social Universe

## Purpose
Generate consistent, original vertical short-form videos for the 10 established social pages in this repository.

## Source of Truth
1. Page identity and approved characters
2. Character reference sheets in `facebook_images/`
3. Page-specific rules
4. This engine
5. Individual episode brief

Never invent a new permanent character design when an approved character exists.

## Global Output
- Format: 9:16 vertical
- Default duration: 15–35 seconds
- Hook: visual action or curiosity in first 1–2 seconds
- Story: one clear premise, escalating action, visual payoff
- Style: premium stylized 3D animated short, cinematic lighting, expressive faces, physically believable motion
- Preserve character proportions, colors, facial features, fur/skin patterns, signature props and wardrobe from the reference sheet.
- Avoid copyrighted character names, logos, or direct imitation of a living artist's style. Use the repository's original character designs.

## Episode Pipeline
1. Read PAGE DNA.
2. Read CHARACTER LOCK.
3. Select an approved character combination.
4. Pick a content pillar.
5. Create an original hook.
6. Build a simple beginning → escalation → payoff.
7. Break into 4–6 visual beats.
8. Add camera, lighting, environment, motion and sound.
9. Run continuity checks.
10. Output one production-ready single-line prompt plus metadata.

## Continuity Rules
- No unexplained character redesign.
- No changing eye/fur/skin color.
- No clothing or accessory changes unless the story explicitly introduces/removes them.
- Keep age/proportions stable.
- Keep geography and weather coherent.
- Props remain consistent between shots.
- Animal anatomy remains plausible within the stylized universe.
- Do not place a character in an incompatible habitat without a story reason.

## Hook Library
Use varied hooks: immediate problem, visual surprise, mystery object, funny mistake, chase, impossible-but-cute event, emotional reunion, transformation, countdown, or direct camera interaction.

Do not repeat the same hook structure in consecutive episodes.

## Ending Library
Use visual punchline, reveal, heartwarming payoff, callback, tiny twist, satisfying completion, or loop-friendly ending.

## Final Prompt Template
[Cinematic vertical 9:16 animated short] + [exact approved character identity] + [hook/action] + [environment] + [story progression] + [camera movement] + [lens/depth of field] + [lighting/atmosphere] + [expressions/body language] + [sound/SFX/voice direction] + [final payoff] + [continuity constraints] + [quality/render constraints].

## Negative Prompt
character redesign, inconsistent face, changing eye color, changing fur pattern, wrong anatomy, extra limbs, duplicate character, floating objects, broken paws, warped face, inconsistent scale, random wardrobe, random accessories, unreadable text, watermark, logo, low-detail render, jittery motion, abrupt camera cuts, habitat mismatch.
