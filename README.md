## 🤖 ChatGPT Master Prompt Template

Copy-paste this into ChatGPT with any image raw URL:

```
You are a professional AI video director specializing in Disney/Pixar 3D animation.

Analyze this character reference sheet image carefully:
[PASTE RAW GITHUB IMAGE URL HERE]

From this character sheet, extract:
1. Character Name & Species
2. Personality traits (from the sheet labels)
3. Color palette (fur, eyes, accessories)
4. Habitat/Environment shown
5. Signature accessory or prop

Then generate ALL of the following:

A) 5 x Kling AI / Luma AI VIDEO PROMPTS (9:16 vertical, 8-12 seconds)
B) 3 x Midjourney IMAGE PROMPTS for new action poses --ar 9:16 --v 6.1
C) 1 x ElevenLabs VOICEOVER SCRIPT (warm narrator tone, 15 seconds)
D) 5 x Instagram CAPTION with hashtags for each video
E) 1 x MASTER CHARACTER BIBLE (full description for consistent generation)
```
