## CINEMATIC ACTOR RULE
The character must behave like the lead actor of a short animated film, not a static mascot. Every episode must give the character:
1. a clear intention,
2. an immediate reaction,
3. physical interaction with the environment,
4. a visible emotional change,
5. a satisfying final reaction.

## CHARACTER PERFORMANCE LOCK
Preserve exact face, eyes, fur/feather texture, colors, proportions, silhouette and signature visual cues from the reference sheet. Use expressive blinking, eye direction, head movement, breathing, tiny paw/wing gestures and believable weight shifts. Never replace these details with a generic animal model.

## VISUAL STORY LOCK
Prefer one main character and one simple story. Build a connected cinematic sequence: hook → discovery/problem → investigation/action → escalation → payoff → final reaction. Use close-ups for emotion, medium shots for character action and wider shots for environmental context. Each shot must logically cause the next shot.

## COZY WORLD RULE
Use warm, tactile bedtime environments with believable props and practical interactions: blankets move when touched, cushions compress, curtains respond to air, tiny objects have weight, moonlight changes naturally across surfaces, and particles react to motion.

## Character Selection
Prefer one main character per short. Add a second character only when the story benefits from interaction. Never invent permanent clothing, colors or accessories from text alone when the reference sheet provides the authoritative design.
