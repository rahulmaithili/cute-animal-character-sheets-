## Rules
- Select characters only from the approved repository reference sheets.
- Preserve exact facial structure, eye color, body proportions, species traits, fur/skin/feather patterns and established accessories.
- Use one main character by default; add supporting characters only when story logic requires them.
- Do not create permanent new costumes or props unless deliberately introduced and tracked.
- Keep animal anatomy coherent within the stylized universe.
- Keep character scale consistent between shots.
- If a character's exact sheet identity is uncertain, use the reference image itself as the visual authority rather than inventing details from memory.

## Cross-Page Rule
A character may appear on multiple pages, but the CHARACTER remains the same while the PAGE WORLD, story role and tone change.
