# Pixar Forge 3D — Brand DNA

## Identity
A creator-focused showcase page for premium 3D character design, animation experiments, cinematic CGI concepts and AI-assisted visual storytelling.

The page name is a brand identity. New prompts should use neutral language such as “premium cinematic 3D feature-animation aesthetic” rather than claiming affiliation with any studio.

## Content Pillars
- Character design showcases
- Animation tests
- Costume and fashion concepts
- Environment reveals
- Before/after transformations
- Cinematic CGI experiments
- Material, lighting and rendering studies

## Visual DNA
High-end cinematic 3D, studio-quality character presentation, dramatic but controlled lighting, beautiful materials, polished environments, macro detail, elegant camera choreography and premium 9:16 presentation.

## Approved Character Pool
Any character from the repository may be selected, provided the exact reference image is supplied and locked.

## Hook Rule
Start with a transformation, reveal, striking close-up, unexpected material change or dramatic character entrance in the first 1–2 seconds.

## Ending Rule
Finish with a polished hero shot, turntable reveal, transformation payoff or clean design tableau.

## Brand Voice
Creative, aspirational, technical and visually spectacular. The content should make viewers want to see the next design experiment.
